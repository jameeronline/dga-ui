# Icon Usage

## Installation

Icons are built into the design system. No additional installation required.

```js
import { createIcon } from '@dga-ui/components';
```

## Basic Usage

<Canvas>
  <div dangerouslySetInnerHTML={{ __html: createIcon({ name: 'check-line', size: 24 }) }} />
  <div dangerouslySetInnerHTML={{ __html: createIcon({ name: 'add-line', size: 24 }) }} />
  <div dangerouslySetInnerHTML={{ __html: createIcon({ name: 'settings-4-line', size: 24 }) }} />
</Canvas>

## API

| Prop        | Type               | Default        | Description                         |
| ----------- | ------------------ | -------------- | ----------------------------------- |
| `name`      | `string`           | Required       | Icon name from the available icons  |
| `size`      | `number \| string` | `16`           | Size in pixels or CSS units         |
| `color`     | `string`           | `currentColor` | Icon color (hex, rgb, etc.)         |
| `title`     | `string`           | -              | Accessible title for screen readers |
| `className` | `string`           | `''`           | Additional CSS classes              |

## Accessibility

For meaningful icons (not decorative), provide a title:

```js
// Decorative icon (default)
createIcon({ name: 'search-line' });

// Meaningful icon with accessibility
createIcon({ name: 'user-line', title: 'User Profile' });
```
