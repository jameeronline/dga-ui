# Icon Library

Our design system includes a curated set of icons from [Remix Icon](https://remixicon.com/), a carefully crafted open-source icon set.

## Overview

- **Source**: [Remix Icon](https://remixicon.com/) - MIT License
- **Count**: 81 curated icons (max 100)
- **Categories**: System, Arrows, User & Faces, Document

## When to Use Icons

- **Navigation**: Menu, arrows, back/forward
- **Actions**: Add, edit, delete, search, filter
- **Status**: Check, warning, error, info
- **Communication**: User, share, notification
- **Files**: Folder, document, clipboard

## Browse Icons

Visit the [Icons Listing](/story/components-icon-icons-listing--default) page to:

- Search and browse all available icons
- Copy icon names for use in code
- Copy SVG code directly
- Download SVG files for use in other tools
